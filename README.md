# 🎉 טריוויית בת המצווה של עדן 👑✨

משחק טריוויה קבוצתי אינטראקטיבי ומסונכרן בזמן אמת לאירוע בת המצווה של עדן!

## 🚀 תכונות עיקריות
- **20 שאלות היכרות וכיף על עדן** עם תמונותיה המשולבות במסכים השונים.
- **סנכרון מלא בזמן אמת** באמצעות Socket.io.
- **מסך מנחה ומקרן (`/host.html`)** המציג קוד חדר ו-QR Code גדול לסריקה מיידית מהסמארטפונים.
- **מסך שחקן מותאם לנייד (`/player.html`)** עם כפתורי מענה צבעוניים בסגנון Kahoot.
- **ניקוד דינמי**: בונוס מהירות + בונוס רצף הצלחות (Streaks 🔥).
- **פודיום מנצחים אולימפי** בסיום עם גביעים, קונפטי וצלילים חגיגיים.

## 🛠️ פריסה ב-Render (Deploy to Render)
1. יצירת Web Service חדש ב-Render.
2. הגדרות:
   - **Runtime**: `Node`
   - **Build Command**: `npm install`
   - **Start Command**: `node server.js`
   - **Instance Type**: `Free`
